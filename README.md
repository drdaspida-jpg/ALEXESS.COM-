# Alexess Technology Website

Complete compiled front-end project for Alexess Technology.

## Included
- Responsive multi-page HTML website
- Homepage
- Shop/catalogue
- Product detail
- Services
- Solar solutions
- CCTV solutions
- About
- Contact form
- Cart using localStorage
- Demo checkout
- Responsive CSS and animations
- JavaScript interactions

## Project structure
- `index.html`
- `shop.html`
- `product.html`
- `services.html`
- `solar.html`
- `cctv.html`
- `about.html`
- `contact.html`
- `cart.html`
- `checkout.html`
- `style.css`
- `responsive.css`
- `animations.css`
- `main.js`
- `products.js`
- `cart.js`
- `checkout.js`
- `contact.js`
- `assets/`

## Important
The checkout and contact forms are front-end demos. Before production deployment, connect them to a backend/email service and payment gateway.

The `assets/` folders are ready for the final Alexess logo, product images, solar images, CCTV images, icons and banners from the design stages.
